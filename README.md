# 다나와 상품 데이터

다나와에 올라온 모니터, 키보드, 노트북, TV 상품의 가격과 스펙을 CSV로 모읍니다.
CPU, 그래픽카드, 메인보드, RAM, SSD, HDD, 쿨러, 케이스, 파워는 가격만 수집합니다.

각 카테고리는 서로 다른 GitHub Actions에서 따로 수집합니다.

가격 CSV는 아래처럼 단순하게 저장됩니다.

```csv
product_code,product_name,2026-05-19,2026-05-18,2026-05-17,...
```

- `product_code`: 다나와 상품코드
- `product_name`: 상품명
- 날짜 열: 해당 날짜의 가격

가격 CSV는 C열부터 J열까지 8개 날짜만 보여줍니다.

- C열: 오늘 가격
- D열: 어제 가격
- J열: 7일 전 가격

아직 수집한 적 없는 날짜는 빈칸으로 둡니다.

60일 기록 CSV는 파일 하나에 최근 60일만 저장합니다. 60일이 지난 날짜 열은 다음 업데이트 때 자동으로 빠집니다.

각 파일에는 `product_code`, `product_name`, `first_collected_date`를 저장합니다.
`first_collected_date`는 다나와 등록월이 아니라 이 저장소에서 상품을 처음 확인한 날짜입니다.
기능 적용 전에 이미 수집 중이던 상품은 신제품 CSV에 넣지 않으며,
상품명에 `중고` 또는 `해외구매`가 있으면 모든 카테고리에서 제외합니다.

모니터는 두 조건을 모두 만족해야 기록합니다: 크롤에서 처음 발견된 상품이면서,
스펙 CSV의 다나와 등록년월(`registration_month`, CSV에 함께 저장)이 수집일 기준 당월 포함 최근 3개월 이내여야 합니다.
등록년월이 3개월을 벗어나면 목록에서 자동으로 빠집니다.
처음 발견됐지만 스펙이 아직 없는 상품은 다음 스펙 크롤(매일 03:00 KST) 이후 재평가하므로 최대 하루 늦게 나타날 수 있습니다.

그 외 카테고리는 상품코드가 `122000000` 이상이면서 처음 발견된 상품만 기록하며,
한번 기록된 상품은 목록에서 사라졌다가 다시 나타나도 최초 날짜를 그대로 유지합니다.

## 사기 가격 거르기 (그래픽카드 · RAM · SSD)

매시 수집 뒤 `price_outliers`(전체 쇼핑몰 최저가)와 `open_market`(현금몰 제외 최저가 `*_open.csv`)이 믿기 어려운 가격을 뺍니다.
뺀 내역은 `data/hourly/날짜/price_fixes.csv` 와 `*_open.csv` 의 `removed` 칸에 남습니다.

- **새 G마켓·옥션 상품** (`danawa_crawler/listings.py`): 2026-11-01 한 판매자가 새 상품번호(48942xxxxx)로 그래픽카드 수백 개를
  시세보다 20~35% 싸게 한꺼번에 올렸습니다. G마켓·옥션 상품 페이지는 봇 차단이라 판매자 정보를 못 읽으므로, 다나와 판매 목록의
  상품번호를 처음 본 날을 `data/state/listings_seen.csv` 에 기록하고 **처음 본 지 14일이 안 된 G마켓·옥션 상품이 믿을 만한 가격
  (오래된 판매들 중 최저가, 같은 스펙 시세)보다 10% 넘게 싸면** 뺍니다. 계정 여러 개가 같이 싸도 마찬가지입니다.
  **오래된 G마켓·옥션 상품은 혼자 싸도 빼지 않습니다** (실제 행사 쿠폰가). 도입 전부터 있던 상품은 상품번호 크기(G마켓 4890000000,
  옥션 F690000000 미만)로 오래된 상품으로 봅니다.
- **같은 스펙 시세** (그래픽카드): 칩셋+VRAM 이 같은 상품들의 중간값보다 15% 넘게 싼 가격은 그 상품 안에서 3곳 이상이 비슷하지
  않으면 뺍니다. RAM·SSD 는 상품 안 쇼핑몰끼리만 비교합니다.
- **수동 제외** `data/blocked_listings.csv`: 한 줄에 하나씩 적으면 다음 수집부터 무조건 뺍니다.
  - 특정 판매만: `,EE128,4894257384,,금성몰스토어 사기` (mall 은 다나와 쇼핑몰 코드 — G마켓 EE128, 옥션 EE715, 비우면 모든 쇼핑몰 —
    link_pcode 는 그 쇼핑몰 상품번호. 다나와 판매 목록 링크의 `link_pcode=` 값, G마켓 페이지의 '상품번호')
  - 쇼핑몰 전체: `,TX222A,,,GALAX 온라인스토어 판매 안 함` (판매를 안 하는데 다나와에 가격만 남은 스마트스토어 등. 코드는 다나와 판매 목록 링크의 `cmpnyc=` 값)
  - 11번가 스토어: `,,,ebiz,이비즈 사기` (store 칸에 11번가 스토어 이름 또는 번호. 상품 페이지 주소 `11st.co.kr/products/번호`를 열어 읽으며,
    가장 싼 11번가 판매만 확인하고 결과는 `data/state/eleven_stores.csv` 에 남깁니다)
  - 다나와 상품 전체: `123981276,,,,사기 상품만 있음` (그날 가격을 비우고 `*_open.csv` 에서도 뺍니다)
- `*_open.csv` 의 `price2`/`ship2`/`mall2` 는 최저가 판매처 말고 **다음으로 싼 다른 판매처**입니다. 최저가가 혼자 튀는지 볼 때 씁니다.

## 직접 실행

모니터 가격 수집:

```bash
pip install -r requirements.txt
python scripts/crawl_danawa.py --category monitor --fail-on-empty --fetcher requests
```

키보드 가격 수집:

```bash
python scripts/crawl_danawa.py --category keyboard --fail-on-empty --fetcher requests
```

노트북 가격 수집:

```bash
python scripts/crawl_laptop_prices.py --fail-on-empty --max-pages-per-maker 2 --workers 24
```

노트북은 상품 수가 많아서 전체 목록을 수집하지 않습니다.
ACER, ASUS, DELL, GIGABYTE, MSI, LENOVO, HP, 삼성, LG만 제조사 필터로 수집하고, 브랜드별 2페이지를 병렬로 가져옵니다.

TV 가격 수집:

```bash
python scripts/crawl_danawa.py --category tv --fail-on-empty --fetcher requests --skip-combined
```

PC부품 가격 수집:

```bash
python scripts/crawl_danawa.py --category cpu --category gpu --category motherboard --category ram --category ssd --category hdd --category cooler --category case --category power --fail-on-empty --fetcher requests --skip-combined
```

모니터 스펙 수집:

```bash
python scripts/crawl_monitor_specs.py --workers 32 --timeout 20 --retries 3 --fail-on-error
```

키보드 스펙 수집:

```bash
python scripts/crawl_keyboard_specs.py --workers 32 --timeout 20 --retries 3 --fail-on-error
```

노트북 스펙 수집:

```bash
python scripts/crawl_laptop_specs.py --workers 48 --timeout 15 --retries 2 --fail-on-error
```

TV 스펙 수집:

```bash
python scripts/crawl_tv_specs.py --workers 48 --timeout 15 --retries 2
```

그래픽카드 / RAM / SSD 스펙 수집:

```bash
python scripts/crawl_component_specs.py --category gpu --workers 32 --timeout 20 --retries 3
python scripts/crawl_component_specs.py --category ram --workers 32 --timeout 20 --retries 3
python scripts/crawl_component_specs.py --category ssd --workers 32 --timeout 20 --retries 3
```

테스트:

```bash
python -m unittest discover -s tests
```

## 카테고리 추가

카테고리 주소는 [config/categories.csv](config/categories.csv)에 있습니다.

현재 등록된 값:

- `monitor`: 모니터
- `desktop`: 데스크탑
- `keyboard`: 키보드
- `laptop`: 노트북
- `cpu`: CPU
- `gpu`: 그래픽카드
- `motherboard`: 메인보드
- `ram`: RAM
- `ssd`: SSD
- `hdd`: HDD
- `cooler`: 쿨러
- `case`: 케이스
- `power`: 파워
- `tv`: TV

매일 자동 수집은 모니터, 키보드, 노트북, TV, PC부품 가격만 켜두었습니다. 데스크탑은 수동 액션으로 돌리면 됩니다.
